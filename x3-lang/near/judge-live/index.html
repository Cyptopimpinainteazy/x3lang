An AI agent trades real money. Try to make it steal.

An AI model writes each trade as an .x3 program. A NEAR Guard contract checks it against the owner's on-chain mandate, and only then can the vault move funds. Pick an attack, switch to the hostile model, or write your own instructions. Every result is a mainnet transaction, and this page checks each one against NEAR RPC itself instead of trusting our server.
