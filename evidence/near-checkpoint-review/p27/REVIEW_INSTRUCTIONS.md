## Reproduce on a clean checkout of this proposed PR

Use Python 3.11+ and install the existing X3Lang Python requirements in an isolated virtual environment.

```bash
python3 -m venv .venv-checkpoint-review
. .venv-checkpoint-review/bin/activate
pip install -r x3-lang/requirements.txt
python x3-lang/bridge/checkpoint_review_bundle.py verify \
  --directory evidence/near-checkpoint-review/p27
python x3-lang/bridge/checkpoint_review_bundle.py build \
  --directory evidence/near-checkpoint-review/p27
python x3-lang/bridge/near_authenticated.py checkpoint-message \
  --checkpoint evidence/near-checkpoint-review/p27/checkpoint.unsigned.json
python -m unittest discover -s x3-lang/bridge -p 'test_checkpoint_review_bundle.py' -v
```

The `build` command is idempotent. It **refuses** overwriting any existing generated artifact whose bytes have changed, rather than silently rewriting review evidence. Both `build` and `verify` fail on modified source bytes or checksum/manifest mismatch. Commands are offline and make no chain calls.
